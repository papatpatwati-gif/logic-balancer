📖 Panduan Penggunaan

LOGIC BALANCER 1.0 – Smart Finance Assistant

1. Pengenalan Aplikasi

Logic Balancer 1.0 adalah aplikasi pengelola keuangan pribadi yang membantu pengguna mengatur pendapatan, pengeluaran, tabungan, serta memberikan nasehat keuangan islami.

2. Profil Pengguna

👤 Foto Profil

Digunakan sebagai identitas visual pengguna.

  • Klik ikon 👤
  • Pilih foto dari perangkat
  • Foto otomatis tersimpan

🧑 Status Pengguna

Status digunakan untuk menyesuaikan gaya nasehat keuangan.

  • Umum
  • Pelajar / Mahasiswa
  • Ibu Rumah Tangga
  • Buruh / Karyawan
  • Wirausahawan

3. Kalender Riwayat Keuangan

Kalender menampilkan riwayat data keuangan bulanan.

  • Tanggal berwarna → ada data
  • Lingkar emas → hari ini
  • Klik tanggal untuk membuka data lama

4. Pengaturan Tema

  • 🌸 Soft → Tema terang
  • 🕶️ Elegan → Tema gelap

Tema akan tersimpan otomatis dan digunakan kembali saat aplikasi dibuka.

5. Input Keuangan

💰 Pendapatan Bulanan

Masukkan total pendapatan Anda dalam satu bulan. Wajib diisi.

✍️ Refleksi Harian

Catatan perasaan, kejadian, atau kebiasaan keuangan hari ini.

📶 Internet / Pulsa

Biaya komunikasi bulanan.

🏠 Kebutuhan Rutin

Pengeluaran pokok seperti makan, listrik, transportasi, dll.

6. Wishlist (Barang Impian)

  • Isi nama barang impian
  • Klik 🔍 untuk mencari harga di Google
  • Masukkan harga barang

7. Audit Keuangan

Klik tombol AUDIT KEUANGAN SAYA untuk:
  • Menghitung tabungan
  • Menghitung cadangan dana
  • Menghitung sisa belanja
  • Mendapatkan nasehat islami dari AI
  • Menyimpan data ke kalender

8. Hasil & Analisis

📊 Rangkuman Keuangan

  • Tabungan (10%)
  • Cadangan Dana
  • Sisa Belanja Harian

📈 Progress Wishlist

Menunjukkan apakah sisa belanja cukup untuk membeli barang impian.

🍩 Grafik Keuangan

Grafik donut menampilkan perbandingan seluruh komponen keuangan.

9. Navigasi

  • Kembali ke Input → Ubah data
  • Logout → Keluar dari akun dengan aman

10. Tips Penggunaan

  • Gunakan setiap hari
  • Isi refleksi dengan jujur
  • Utamakan kebutuhan daripada keinginan
  • Jadikan aplikasi sebagai alat muhasabah

Penting: Status PRO diperlukan untuk akses penuh. Jika status belum aktif, silakan kirim bukti transfer ke Admin.
